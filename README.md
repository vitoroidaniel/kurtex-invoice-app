## ✨ What is OILLOG?

OILLOG is a modern fleet management app built for **yard operations**. Field agents log oil changes from their phones, while managers monitor everything from a powerful admin dashboard.

| | |
|:---|:---|
| 📱 **Mobile App** | Log oil changes in seconds with a clean, mobile-first interface |
| 🖥️ **Admin Panel** | Dashboard, entries, units, alerts, and user management |
| 🔐 **Secure Auth** | Username/password with salted password hashing |
| 📊 **Excel Export** | Professional reports with one click |
| ⚡ **Real-time Sync** | All devices stay in sync every 5 seconds |
| 📲 **PWA Ready** | Install on phones like a native app |
| 🌗 **Themes** | Dark & light modes for any environment |

## 🚀 Quick Start

```bash
pip install -r requirements.txt
python server.py
```

Visit `http://localhost:8080`

### 🌐 Environment Variables

| Variable | Description |
|:---|:---|
| `OILLOG_SECRET` | Flask session secret key |
| `OILLOG_DATA_DIR` | JSON data directory (default: `/app/data`) |
